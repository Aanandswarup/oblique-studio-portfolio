# Oblique Studio — Cinematic 3D Design Agency Portfolio 🎬✨

A cinematic, interactive digital design agency website built with **Next.js 16**, **React 19**, **Three.js / React Three Fiber (R3F)**, **GSAP**, and **Tailwind CSS 4**.

## 🌟 Key Features

- **Scene 1 (Hero)**: Interactive 3D WebGL hero scene featuring floating geometry with real-time lighting and shadows.
- **Scene 2 (Selected Work)**: High-concept project showcase gallery with rich case studies and interactive preview states.
- **Scene 3 (Manifesto Toy)**: Interactive 3D physics / shader playground celebrating experimental digital craft.
- **Scene 4 (Closing)**: Contact and inquiry section with responsive layout and fluid hover states.
- **Project Drawer**: Slide-out case study detail drawer displaying in-depth project information, deliverables, and metrics.
- **Header HUD**: Minimalist heads-up display navigation with live scroll progress indicator.
- **Custom Cursor & Smooth Scroll**: Integrated custom cursor with state transitions and [Lenis](https://lenis.darkroom.engineering/) smooth scrolling.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router + Turbopack)
- **Library**: [React 19](https://react.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/), `@react-three/fiber`, `@react-three/drei`
- **Animations**: GSAP, CSS Transitions
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.17+ or v20+)
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aanandswarup/oblique-studio-portfolio.git
   cd oblique-studio-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
